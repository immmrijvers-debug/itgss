# ITGSS

Study companion for **320124 — IT Governance & Strategic Sourcing** (Tilburg University).

## Summary feature

- Browse curated **weekly lecture summaries** (key points, frameworks, exam focus)
- **Create a summary** from pasted notes (runs entirely in the browser)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
